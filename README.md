# skill

Claude Code skills.

- `comfyui-music-video/` – give Claude Code a song, a singer image and your ComfyUI API URL; it plans 12 storyboard shots with timings, separates vocals, builds/submits the MiniMax H3 workflow through the ComfyUI API, and stitches the result with the original audio.

Install: copy the folder to `~/.claude/skills/` (or `.claude/skills/` in a project).
